## 已实现的首版范围

- 固定 3×3 电梯平台，两站运行，速度 0.10 格/tick。
- 行程 4–32 格，装配前潜行右键控制器以 4 格递增，默认 8 格。
- 控制器组装平台；右键控制器或平台切换目标站。
- 遥控器绑定控制器，对空中右键呼至下站，潜行右键呼至上站，限制同维度、64 格范围。
- 服务端决定平台位置，客户端插值；平台通过原版实体碰撞形成承载表面。
- 控制器保存平台 UUID，平台保存控制器、行程和目标。卸载时不凭空补生平台；控制器失效后平台在加载时移除。
- 每 tick 验证移动空间和头部空间，障碍或区块未加载时暂停。
- 模块式扶梯踏步：朝向决定上行方向，右键反向，红石信号暂停，潜行不输送。
- 创造标签页、三种合成配方、掉落表、镐工具标签、中英文名称及提示。

### 不在本次原型范围内

封闭轿厢、轿门/厅门及门联锁、任意方块组装轿厢、多楼层调度、踏步循环动画、机械传动、音效与定制美术、旧存档迁移和其他模组联动。这些都不能标记为“完成”。

## 电梯使用

1. 放置电梯控制器。平台底面位于控制器上表面，高 0.25 格。
2. 控制器正上方留出 **3×3** 的竖直净空，贯穿全部行程，并在上站另留 **2.25 格头部空间**。不要在平台通道内铺实体方块地板。
3. 装配前，空手潜行右键控制器调整行程。
4. 空手普通右键控制器装配平台。再次右键控制器或平台切换上/下站。
5. 手持遥控器右键控制器绑定，随后对空中使用：普通右键下站，潜行右键上站。
6. 两站的接驳地面应在平台外侧。平台站立面为 `控制器Y + 1.25` 和 `控制器Y + 1.25 + 行程`；可使用地毯/活板门等自行规划过渡，但不得侵入扫掠空间。
7. 调整已装配电梯需拆除控制器，再放置并设置；旧平台在确认原控制器不再拥有它时移除。拆除操作由玩家在游戏中自行进行。

**原型风险：** 无门和安全围栏，请勿在生存重要世界使用。未完成实际载人测试，存在抖动、踩空、跳跃时误判、乘客和方块碰撞差异等风险。平台阻塞时保留目标，清障后继续。

## 扶梯使用

把踏步按一格水平、一格垂直的楼梯排列，全部朝向上站（放置时沿着上行方向看）。碰撞是下半块加上半阶，外观借用原版楼梯模型。

- 空手右键每个踏步切换反向；方向需逐块一致。
- 向踏步提供红石信号暂停该踏步。
- 实体站在踏步上时由步行回调输送；潜行可停止。
- 目前是固定阶梯输送原型，不是带循环动画的真实机械扶梯。连续过阶、顶棚、多人输送等须实测。

## 构建与安装

设置 `JAVA_HOME` 指向 JDK 21：

```text
./gradlew build
./gradlew :fabric:runClient
./gradlew :neoforge:runClient
```

Wrapper 固定 Gradle 8.8。输出：

- `fabric/build/libs/elevators_escalators-fabric-0.1.0-dev.jar`
- `neoforge/build/libs/elevators_escalators-neoforge-0.1.0-dev.jar`

安装对应加载器与对应平台 Architectury API 13.0.8；Fabric 另外安装 Fabric API。不要同时安装两个平台 JAR，不要使用 dev-shadow 或 sources JAR。

代理不写入工程。必要时将本机代理通过 JVM 参数传递给 Gradle，例如 `-Dhttps.proxyHost=127.0.0.1 -Dhttps.proxyPort=7897 -Dhttp.proxyHost=127.0.0.1 -Dhttp.proxyPort=7897`，按实际端口修改。
